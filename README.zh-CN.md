# Samsara

[English README](README.md)

**自托管、可安全自我改进的智能体运行时。** Samsara 为递归自我改进(RSI)而生,但绝不以
牺牲可审计性、可逆性和控制权为代价:一切状态变化落入哈希链追加式账本,一切副作用
可逆或有交代,一切自我修改经过分级授权闸门。

> **Samsara**(轮回)——名字即架构:回滚、重放、改进,循环不息。

[设计文档](.context/design/) · [收敛账本](.context/design/closure-ledger.yaml)

---

## Samsara 有何不同

多数智能体框架优化的是*能力*。Samsara 优化的是**可组合的信任**——让递归自我改进
得以幸存的那个属性:

### 1. 时间与空间可组合性(L0 内核)

- **时间可组合性**——每个副作用归入三分类(可逆 / 可补偿 / 不可逆须前置审批),作为
  *效应*登记入账。杀死 agent、卸载插件、回滚到任意历史点——环境都被诚实地还原,
  包括*"回滚一次回滚"*(广义时间旅行:`rollbackTo(seq)` + `redo`)。
- **空间可组合性**——插件经反应式余效应组合:停用一个提供者会级联停用其依赖方,
  依赖回归时等待者自动复活。无论以什么顺序激活,系统都收敛到同一状态。
- **汇流性,被证明**——INV-1("任意激活/停用序列的静止态 ≡ 按依赖序一次性组合的
  最终状态")不是愿景,而是被性质测试(PBT)钉死的性质:数千随机交错全部收敛。

### 2. 账本即真相,其余皆是投影

一切状态迁移——插件生命周期、效应、会话、技能、记忆写入、定时任务、信任变更、
评审——流经**唯一一条哈希链追加日志**(INV-4 单写入者)。其余(SQLite 读模型、
Parquet 轨迹、快照)都是*投影*:可随时删除,重放即重建。崩溃恢复 = 加载快照 +
重放尾部 + 重绑效应。

### 3. 授权代数(M3)

派生的子 Agent 遵循三条强制不等式——能力只减、配额严格递减、权限上限只降——
**任意派生树可证明地必然终止**,无需运行时监督者。深度超软限需 owner 批准
(记入评审账本);硬顶绝对不可逾越。

### 4. 带性能 SLO 的工作区写捕获

会话工作区的文件写入经 copy-on-first-write 覆盖层,整个会话由**一笔**账本效应承载
(而非每写一笔)——100 并发会话实测拦截开销 **1.00–1.04×**(SLO ≤1.10×)。
`commit` 把差异清单归档入内容寻址存储;`discard`/kill 还原到 `git status` 级干净。

### 5. 带投毒防御的三层记忆

情景记忆由对话蒸馏而来(空闲时/关停时);语义记忆跨会话生效,但必须通过**信任闸门
写入路径**(仅 owner、指令/授权模式内容体检、全程溯源)。召回 = 向量相似 → 重排 →
上下文注入;检索不可用时优雅降级为时序。

### 6. 治理即代码

设计本身被版本化并接受机器检查:
- **收敛账本**——90 条裁决条目(written-back / verified / designed),逐条携带
  机检断言;
- **规格常量注册表**——59 个注册常量;代码中每个阈值必须能追溯到文档权威章节;
- **冻结检查器 + 账本断言器**——CI 式门槛,文档漂移即变红。

### 7. 不开入站端口的渠道

微信个人号 Bot(腾讯 iLink):纯出站长轮询——本地渲染二维码的扫码绑定(不经任何
第三方二维码服务)、typing 指示、媒体解密(CDN + AES-128-ECB)、跨重启对话串线、
对端信任派生(绑定者为 owner,陌生人为 guest)、有界车道分发。

## 架构

```
L3  元改进层    分级自我修改(R 闸 + 人审)                            [M4/M5]
L2  经验资产层  技能 / 记忆 / 分支 —— COW、版本树、
                lint+影子闸门的晋升管道
L1  执行层      ReAct 回路、派生器 + 授权代数、
                工作区写捕获、车道队列
L0  可组合内核  Context / 三分类效应 / 反应式余效应 /
                哈希链账本 / 快照 / 崩溃恢复 / 投影
L0.5 接入平面   渠道(微信 iLink、WebChat)、信任栈、worker 隔离
```

五条宪法级不变量(INV-1 汇流性、INV-2 可逆性、INV-3 能力单调衰减、INV-4 单写入者、
INV-5 宪法不可触达)由测试守护——含随机派生树穷尽测试与 kill 无残留
(环境哈希复原)套件。

## 快速开始

```bash
npm install
npm test                                   # 156 项测试
npm run cli -- run "写一句周报"
npm run cli -- webchat                     # 守护:WebChat + 调度器 + 记忆 + 微信
npm run cli -- job add "每周五 9 点写周报"   # 自然语言 → cron
npm run cli -- wechat bind                 # 微信扫码绑定(本地渲染二维码)
npm run cli -- wechat status               # 绑定与轮询状态
npm run cli -- memory ls                   # 三层记忆
npm run cli -- trust ls                    # 对端信任映射
npm run cli -- models ls --refresh         # 模型注册表(凭据永不落盘)
npm run cli -- workspace ls <sessionKey>   # 会话工作区差异
npm run cli -- doctor                      # 账本链 / CAS / 投影 / Parquet 对账
npm run demo                               # 七段内核能力演示
npm run soak                               # M1(34 任务)+ M3 混合负载压测
```

数据目录 `~/.samsara`(或 `$SAMSARA_HOME`):哈希链日志、SQLite 投影、CAS 对象库、
凭据(0600)。投影可随时删除——重放即重建。模型凭据仅从环境变量解析,
永不进入账本、轨迹或日志。

## 开发工作流

一切开发走 **issue → 分支 → PR(squash 合并)**;main 不接受直接提交。
issue 与 PR 使用**英文**书写。PR 可合并的条件:全量测试绿 + 治理双门槛绿:

```bash
npm test
cd .context/design && python3 tools/freeze_check.py && python3 tools/ledger_assert.py
```
